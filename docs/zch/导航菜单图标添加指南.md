# 导航菜单图标添加指南

本文档说明如何在左侧导航菜单中添加图标，以及图标系统的工作原理。

---

## 一、图标工作原理

### 1. 图标数据来源

导航菜单的图标来源于**路由配置的 `meta.icon` 字段**，有两个来源：

**来源 A：静态路由（前端硬编码）**

位于 `src/router/modules/` 下的路由文件，例如：

```typescript
// src/router/modules/tools.ts
export default [
  {
    path: '/tools',
    component: Layout,
    redirect: '/tools/data-formatter',
    name: 'tools',
    meta: {
      title: { zh_CN: '工具箱', en_US: 'Tools' },
      icon: 'tools',  // <-- 图标名称
    },
    children: [
      {
        path: 'data-formatter',
        name: 'DataFormatter',
        component: () => import('@/pages/tools/data-formatter/index.vue'),
        meta: { title: { zh_CN: '数据格式化', en_US: 'Data Formatter' } },
      },
    ],
  },
];
```

**来源 B：动态路由（后端返回）**

后端接口 `/api/sys/menu/list-i18n` 返回的菜单数据中包含 `meta.icon` 字段：

```json
{
  "path": "/dashboard",
  "name": "dashboard",
  "component": "LAYOUT",
  "meta": {
    "title": { "zh_CN": "仪表盘", "en_US": "Dashboard" },
    "icon": "dashboard"  // <-- 图标名称
  },
  "children": [...]
}
```

### 2. 图标渲染位置

图标在 `src/layouts/components/MenuContent.vue` 中渲染，通过 TDesign 的 `t-menu-item` 和 `t-submenu` 组件的 **`#icon` 插槽** 实现：

```vue
<t-menu-item :value="item.path">
  <template #icon>
    <component :is="menuIcon(item)" class="t-icon"></component>
  </template>
  {{ item.title }}
</t-menu-item>
```

### 3. 支持的图标

项目使用 **TDesign 官方图标库** (`tdesign-icons-vue-next`)，图标名称就是 TDesign 图标的名字。

图标查询地址：https://tdesign.tencent.com/vue-next/components/icon

常用图标示例：

| 图标名称 | 含义 |
|---------|------|
| `dashboard` | 仪表盘 |
| `user` | 用户 |
| `setting` | 设置 |
| `file` | 文件 |
| `folder` | 文件夹 |
| `chart` | 图表 |
| `edit` | 编辑 |
| `view-list` | 列表 |
| `bookmark` | 书签 |
| `tools` | 工具 |
| `login` | 登录 |
| `logout` | 退出 |
| `home` | 首页 |
| `layers` | 层级 |
| `app` | 应用 |

## 二、如何添加图标

### 方式一：为静态路由添加图标

在 `src/router/modules/` 下的路由文件中，给需要图标的菜单项添加 `meta.icon`：

```typescript
// src/router/modules/xxx.ts
{
  path: '/your-path',
  name: 'YourName',
  component: Layout,
  meta: {
    title: { zh_CN: '你的菜单', en_US: 'Your Menu' },
    icon: 'dashboard',  // <-- 添加这行
  },
  children: [...]
}
```

### 方式二：为动态路由添加图标

在后端数据库的菜单表中，给对应菜单记录的 `icon` 字段赋值：

```sql
UPDATE sys_menu SET icon = 'dashboard' WHERE name = '仪表盘';
```

或者通过后端管理界面配置。

### 方式三：为子菜单添加图标

子菜单（children）也可以单独设置图标：

```typescript
children: [
  {
    path: 'base',
    name: 'ListBase',
    component: () => import('@/pages/list/base/index.vue'),
    meta: {
      title: { zh_CN: '基础列表', en_US: 'Base List' },
      icon: 'view-list',  // <-- 子菜单图标
    },
  },
]
```

> **注意**：子菜单图标只在部分布局模式下显示，侧边栏布局中通常只有一级菜单显示图标。

## 三、完整恢复图标显示（批量添加）

当前项目中图标已被移除。如果要恢复图标显示，需要修改 `src/layouts/components/MenuContent.vue`：

### 步骤 1：恢复 icon 字段映射

在 `getMenuList` 函数中，把 `icon` 字段加回来：

```typescript
const getMenuList = (list: MenuRoute[], basePath?: string): MenuRoute[] => {
  // ... 排序代码 ...
  return list
    .map((item) => {
      const path = basePath && !item.path.includes(basePath) ? `${basePath}/${item.path}` : item.path;
      return {
        path,
        title: item.meta?.title,
        icon: item.meta?.icon,  // <-- 添加这行
        children: getMenuList(item.children, path),
        meta: item.meta,
        redirect: item.redirect,
      };
    })
    .filter((item) => item.meta && item.meta.hidden !== true);
};
```

### 步骤 2：添加图标渲染函数

在 `<script>` 中添加 `menuIcon` 函数：

```typescript
const menuIcon = (item: MenuRoute) => {
  if (typeof item.icon === 'string') return <t-icon name={item.icon} />;
  const RenderIcon = item.icon;
  return RenderIcon;
};
```

### 步骤 3：在模板中添加 icon 插槽

为 `t-menu-item` 和 `t-submenu` 添加 `#icon` 插槽：

```vue
<template v-for="item in list" :key="item.path">
  <template v-if="!item.children || !item.children.length || item.meta?.single">
    <t-menu-item :name="item.path" :value="getPath(item)" :to="item.path">
      <template #icon>
        <component :is="menuIcon(item)" class="t-icon"></component>
      </template>
      {{ renderMenuTitle(item.title) }}
    </t-menu-item>
  </template>
  <t-submenu v-else :name="item.path" :value="item.path" :title="renderMenuTitle(item.title)">
    <template #icon>
      <component :is="menuIcon(item)" class="t-icon"></component>
    </template>
    <menu-content v-if="item.children" :nav-data="item.children" />
  </t-submenu>
</template>
```

## 四、自定义图标（非 TDesign 图标）

如果需要使用自定义 SVG 图标或其他图标库：

### 使用 SVG 图标

1. 将 SVG 文件放入 `src/assets/` 目录
2. 在路由中引入并使用：

```typescript
import MyIcon from '@/assets/my-icon.svg?component';

{
  path: '/custom',
  meta: {
    title: '自定义',
    icon: MyIcon,  // <-- 传入组件，不是字符串
  },
}
```

`menuIcon` 函数会自动处理组件类型的图标：

```typescript
const menuIcon = (item: MenuRoute) => {
  if (typeof item.icon === 'string') return <t-icon name={item.icon} />;
  const RenderIcon = item.icon;  // <-- 组件类型直接渲染
  return RenderIcon;
};
```

### 使用其他图标库

例如使用 `tdesign-icons-vue-next` 以外的图标：

```typescript
import { SomeIcon } from 'some-icon-library';

{
  meta: {
    icon: SomeIcon,
  }
}
```

## 五、常见问题

### Q: 添加了图标但不显示？

检查以下几点：

1. **图标名称是否正确** — 必须是 TDesign 图标库中存在的名称，区分大小写（全部小写）
2. **是否在 `meta` 中配置** — 图标必须放在 `meta.icon`，不是 `icon`
3. **路由是否被隐藏** — 检查 `meta.hidden !== true`
4. **是否已刷新页面** — Vue Router 配置变更需要刷新页面生效

### Q: 如何查看所有可用的图标？

访问 TDesign 官方图标列表：

https://tdesign.tencent.com/vue-next/components/icon

或者在项目中搜索：

```bash
# 查看 tdesign-icons-vue-next 提供的所有图标
ls node_modules/tdesign-icons-vue-next/esm/components/
```

### Q: 动态路由和静态路由的图标冲突？

动态路由（后端返回）会覆盖静态路由。如果同一菜单同时存在，以动态路由的 `meta.icon` 为准。

### Q: 图标大小不对？

TDesign 菜单组件会自动控制图标大小（默认 20px）。如需自定义，可以覆盖 CSS：

```css
.t-menu .t-icon {
  font-size: 18px;
}
```
